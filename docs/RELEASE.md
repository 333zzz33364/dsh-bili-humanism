## DSH B站内容学习插件 v0.1.0

> 寄往明日的信笺｜让AI看见多彩的世界

版本：v0.1.0（预览版）

一个可安装的 DSH 插件：B站 A2/A1 取稿 → 保留作者、时间点和材料限度 → 人文问题导向的证据手账 → 本地 HTML/Markdown 收件箱 → 可查看、纠正、删除的记忆。

Windows 上通过 DSH Desktop 内置 CLI 0.2.1-rc.2 的隔离安装与工具调用；17 项离线与 SDK 契约测试通过，A2/A1 做过真实读取功能检查。具体案例和手账留在本地，未进行准确性或性能对照实验。

本版默认手动运行，当前尚未实现或开放 B站平台写入执行器，无后台调度。后续可在安全策略和具体授权允许的条件下接入独立写入模块，须先完成实现和验收。请求与候选硬预算、缓存去重、取消、任务互斥、进程退出恢复、异常跨重启暂停已实现。SESSDATA 仍是高敏登录凭据，当前读取模块由程序限制接口范围，不能承诺零平台风险。

已提供可选本地 ASR / 抽样帧适配器与导入接口，但真实推理未验收；没有自动 OCR 或独立侧栏。7 天私人运行、20 视频人工基准、桌面安装界面与其他宿主组合仍待验证。

安装：下载本 release 的 tgz，核对 SHA256SUMS.txt，运行 `dsh plugin --profile web add ./dsh-bili-humanism-0.1.0.tgz`。插件入口为 JavaScript，不需要运行安装构建脚本。详情见 README 与 docs/ACCEPTANCE.md。

源码和安装包不含个人日记、凭据、第三方视频全文、媒体、权重或角色素材。此 release 尚未发布 npm registry。
