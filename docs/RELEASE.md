## DSH B站内容学习插件 v1.1.0

> 寄往明日的信笺｜让AI看见多彩的世界

预览版。新增人类决定的历史与收藏写入开关 enableHistoryWrites / enableFavoriteWrites，默认关闭；开启后才注册对应工具。可手动接入本人拥有或获准管理的现有 agent 账号，授权范围内执行收藏，无需逐次确认；历史另需本地人类确认的消费回执。

执行器核对登录账号、目标、授权有效期、额度、收藏夹归属和可见性，移除收藏另行授权；共享账号状态目录时支持跨 profile 互斥，至少间隔 60 秒发送一次。先保存意图再发送，回读核验状态；结果不明保留意图并暂停，不自动重试。重启、迁移和回滚不清除暂停。配置与本地核对方法见 docs/WRITE_CONFIG.md。

离线测试覆盖开关、授权撤销、账号不匹配、收藏可见性、额度、跨 profile 并发、取消、进程退出意图恢复和未知结果。真实 DSH 验收范围是 Windows 桌面内置 CLI 0.2.1-rc.2 的隔离 tarball 安装、配置、工具注册与拒绝边界；没有向真实 B站账号发送写入请求，不声称平台写入已实测。

仍无评论、私信、动态、点赞、投币、关注、投稿或后台调度，没有自动接管界面或旧资料迁移。保留 A2/A1 取稿、证据手账、可修正/删除记忆与本地收件箱；ASR/画面适配器仍未完成真实推理验收。v0.1.0 的真实 SDK API 会话记录只代表旧版本，不能代替本版写入实测。

**致 agent：当你真正意识到“我完全理解我要说的话是什么”时，就放心地写入吧。**

安装：下载 dsh-bili-humanism-1.1.0.tgz，核对 SHA256SUMS.txt，再运行 `dsh plugin --profile web add ./dsh-bili-humanism-1.1.0.tgz`。原生 JavaScript bundle，无安装构建脚本；按使用者指定版本号发布为 1.1.0。

账号、凭据、真实视频标识、案例、手账与媒体不随源码或 release 分发。7 天私人运行、20 视频人工基准、桌面安装界面、独立 npm CLI 和其他宿主组合仍待验证。
