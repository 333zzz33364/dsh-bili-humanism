## DSH B站内容学习插件 v1.4.0

发布包为 `dsh-bili-humanism-1.4.0.tgz`，校验文件为 `SHA256SUMS.txt`。105 项离线测试通过；发布前对最终 tarball 执行隔离宿主的22配置场景和独立图片附件验收，最终通过结果及 SHA-256 记录在对应 GitHub Release。

此前发布版没有插件自身的视频下载链路：文字读取自动取字幕，本地抽帧要求另行准备视频。1.4.0 增加固定来源的视频获取、抽帧和宿主图片附件交付。支持图片输入及附件服务的路由读取链接时，可在同一任务中取得文字与首四张画面；已有来源可单独获取图片或按四张一页继续读。

- 固定 playurl qn=32，最高 480p；DASH 轨必须有有效尺寸/清晰度/带宽，支持短边不超过 480、长边不超过 1920、总像素不超过 921600 的横屏与竖屏。无 DASH 时仅接受单段 durl，并在解码前与逐帧检查相同边界及来源时长。
- 文字与自动画面共享最多 12 请求、90 秒；来源最多 600 秒，视频最多 32 MiB，抽样最多 40 张 JPEG。保留 HTTPS/CDN 白名单、重定向拒绝、凭据不发往 CDN 以及持久风控暂停。
- 先预检独立 Python 环境；可信人工 pythonPath 指定绝对解释器路径，模型无路径/命令/URL设置参数。依赖不足时保留已有文字但明确没有画面；取消、预算、风控及凭据错误不会被视觉回退吞掉。
- 下载视频属于插件私有单次中间文件，成功、失败、取消及超时均在子进程关闭后 finally 清理。核对创建时的文件和目录身份，只删一个确切拥有的视频与空任务目录；保留帧、manifest、来源和全部外部原件。清理失败不提交成功索引。硬终止/断电不保证 finally，没有后台扫盘删除。
- 图片经固定 DSH 附件协议交给宿主，按时间戳保留抽样覆盖和不确定性。字幕、抽帧成功或图片交付不等于完整观看或语义理解；没有内置视觉权重、自动 OCR 或模型下载器。

一次真实匿名500秒来源的只读验收完成最高480p下载与抽帧：4个GET、34张帧，临时视频已清理且任务中间目录为空。这是单次来源链路结果，不证明完整理解、识别准确率或长期稳定性。宿主附件验收使用合成图片与合成能力路由，验证原生存储和输出协议，不调用真实模型。合成回归覆盖下载失败、解码失败、取消、超时、预算/重定向、风控、索引完整性和外部原件保留。

人格积累默认开启，历史、收藏、点赞与投币继续独立默认关闭，评论不开放。手账、完整分卷、每日上限、账号额度、未知回执和持久暂停保留。SQLite schema 仍为 1；回滚须保留全部私人资料和最新控制状态。

核对 SHA256SUMS.txt 后执行 `dsh plugin --profile web add ./dsh-bili-humanism-1.4.0.tgz`，并重载同一 profile。JavaScript bundle 无 prepare/build 或自动 pip 安装脚本。安装后入口见 docs/GETTING_STARTED.md；抽帧依赖和解释器配置见 docs/LOCAL_FRAMES.md；升级与回滚见 docs/MAINTENANCE.md。
