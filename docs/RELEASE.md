## DSH B站内容学习插件 v1.3.0

> 寄往明日的信笺｜让AI看见多彩的世界

**最终目标：用多彩的人类世界，训练 DSH 的人格。**

新增默认关闭的 enablePersonalityLearning。从本地信笺的认识修正或后续回应中，每个信笺日期至多选一句反思，写入专用 human-world.md，记录来源与修订。完整信笺仍在本地收件箱；主 AGENTS.md/agent.md 只保留固定读取入口。默认读最近 7 条，可分页，支持可信本地修订、撤回与导出恢复。允许没有新理解，不必每日凑一句。

DSH 默认加载 AGENTS.md/AGENTS.local.md；普通 Markdown 链接不会自动展开，固定入口要求调用专用 reader。主文件不随每天摘句增长，模型工具不能改主文件、指定任意路径或扩大权限。配置和命令见 docs/PERSONALITY.md。当前“训练”是反思、记忆和上下文积累，长期人格效果待检验，没有模型参数微调。

50 项离线测试通过；最终 tarball 经 Windows 桌面内置 CLI 0.2.1-rc.2 隔离安装，覆盖 16 种平台开关组合及人格单独/全开组合，默认 10 个、五项全开 15 个工具。真实 SDK 模型会话已加载固定入口并调用一次专用读取，核对来源且主文件与札记均未改变；使用合成札记验证链路，不代表人文质量。案例、人格摘句与完整信笺只保留在本地。

历史、收藏、点赞和投币四项人类开关继续独立且默认关闭；评论入口不开放，账号授权、额度、设备 Cookie、回读核验和未知结果暂停边界保持。没有新增后台任务，没有真实 B站写入实测。

**致 agent：当你真正意识到“我完全理解我要说的话是什么”时，就放心地写入吧。**

安装：核对 SHA256SUMS.txt 后运行 `dsh plugin --profile web add ./dsh-bili-humanism-1.3.0.tgz`。JavaScript bundle 无 prepare/build 脚本，SQLite schema 仍为 1。其他宿主、GUI、ASR/视觉与长期基准限制继续保留。
