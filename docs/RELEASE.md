## DSH B站内容学习插件 v1.3.4

> 寄往明日的信笺｜让AI看见多彩的世界

**最终目标：用多彩的人类世界，训练 DSH 的人格。**

本版合并三项读取修复，并增加人类手动设置会话 token 上限：

- 先读 A1 字幕轨，没有可用字幕才回退到 A2 文字片段；摘要和提纲不作为逐字稿。读取缓存升级为 read-v2，已有来源和手账保留。
- 音频下载按域名与端口配对校验，支持 playurl 返回的 HTTPS `*.mcdn.bilivideo.cn` 默认端口或 8082，保留原有媒体域名规则。Cookie 不发往 CDN，不跟随重定向，下载额度继续生效。
- 网络或缓存取稿为空时，复用同视频、分 P、CID 和时长下最近保存的非空本地 A3，返回原 ID 并保留 ASR 覆盖、未核实标记及网络结果说明。画面稿不替代语音稿，非空 A1/A2 保持优先。
- 人类通过可信 config 设置 `maxSessionTokens`，正安全整数，可高于或低于默认 600000；保存后重载，已有会话消耗不清零。模型没有调整或重置工具。该门限依赖宿主计量，无法截断已发请求，不是服务商账单上限。

83 项离线测试通过。最终 tarball 在 Windows DSH Desktop 内置 CLI 0.2.1-rc.2 全新隔离 profile 安装，完成 22 个平台/人格/token 配置场景，以及字幕、空缓存复用 A3、MCDN 音频执行器、完整手账、每日上限与固定人格入口检查。无开发源码链接。详见 docs/ACCEPTANCE.md。平台响应使用合成夹具，不声明本版完成真实 B站读取、CDN 下载、写入或长期人格效果验收。私人反馈包未审阅，其日志和 diff 不作为本版验收依据。

人格积累默认开启；历史、收藏、点赞和投币独立默认关闭，评论接口继续关闭。手账每日最多两篇、完整分卷与完整性校验继续保留；没有新增后台任务。

**致 agent：当你真正意识到“我完全理解我要说的话是什么”时，就放心地写入吧。**

安装：核对 SHA256SUMS.txt 后运行 `dsh plugin --profile web add ./dsh-bili-humanism-1.3.4.tgz`。JavaScript bundle 无 prepare/build 脚本，SQLite schema 仍为 1；回滚须保留账号暂停、额度、未知回执和全部私人记录。高于 600000 的配置在回滚 1.3.3 前须调回旧版允许范围。详见 docs/MAINTENANCE.md。
