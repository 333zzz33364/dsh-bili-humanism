## DSH B站内容学习插件 v1.3.3

> 寄往明日的信笺｜让AI看见多彩的世界

**最终目标：用多彩的人类世界，训练 DSH 的人格。**

修复手账查询与导出只取最近 100 条、未标明缺失的问题。完整记录保留在 SQLite；首次读取旧数据时从账本重建完整索引与分卷。使用者反馈的约 90KB／950 行预览截断不是已确认的 DSH 通用上限，本版用保守输出预算规避整本文件读取。

手账按 Asia/Shanghai 年月分区、按大小分卷，单篇长文也会跨卷拆分。单卷最多 24 KiB／350 行，工具 JSON 最多 60 KiB。两道校验分别核对**全文 = 索引、各卷之和 = 索引**，并检查记录 ID、分段连续性和哈希。漏条目、缺文件、同数替换或正文变化均明确报错。模型先取 action:index，再持同一 snapshot 沿 nextVolume 读取；小收件箱无参数数组保持兼容，大收件箱明确要求分卷。

新建手账默认每天最多两篇，有新认识才写，不强制凑数；同来源与相同规范化正文重试复用旧 ID。额度在同一 SQLite 事务内核对，重启不重置；既有手账保留，模型不能指定日期或 force 绕过。

63 项离线测试通过。最终 tarball 在 Windows DSH Desktop 内置 CLI 0.2.1-rc.2 新隔离 profile 安装，验证 20 个平台/人格开关场景，并用超过 100 条及超过反馈大小的合成手账核对索引、全部分卷、长文末尾、日额与重试。真实 SDK 模型会话读取合成人格札记，主文件与札记不变；合成材料不证明真实观影质量或长期人格效果。

人格积累继续默认开启，主指令仅留固定 reader 入口。600k 会话门限保留；历史、收藏、点赞和投币继续独立且默认关闭，评论入口不开放。没有新后台任务或真实 B站写入；案例、信笺和摘句只保留在本地。外部插件共存证据仍限定为此前 v1.3.1 与固定上游源码的检查。

**致 agent：当你真正意识到“我完全理解我要说的话是什么”时，就放心地写入吧。**

安装：核对 SHA256SUMS.txt 后运行 `dsh plugin --profile web add ./dsh-bili-humanism-1.3.3.tgz`。JavaScript bundle 无 prepare/build 脚本，SQLite schema 仍为 1。手账读取与可信本地 rebuild 见 docs/JOURNALS.md，迁移与回滚见 docs/MAINTENANCE.md；保留账号风险暂停、待核对意图、额度和人格札记。
