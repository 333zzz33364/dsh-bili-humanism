## DSH B站内容学习插件 v1.3.2

> 寄往明日的信笺｜让AI看见多彩的世界

**最终目标：用多彩的人类世界，训练 DSH 的人格。**

默认会话累计 token 判定门从 60,000 提高到 **600,000**，同时提高底层允许上限，统一 DSH 配置与运行时省略值。显式配置的较小额度继续有效；旧配置若写有 `maxSessionTokens: 60000`，改为 `600000` 或移除该项并重载后才采用新额度。升级保留持久会话基线，不重置已计量消耗。

长视频精读继续按 `bili_humanism_source` 的 `next_offset` 逐页读取，分段保存理解、时间点与未读进度。600k 是同一宿主会话自首次带计量调用后的累计增量，含其他会话工作；它不是单次上下文容量，也不能截断已发出的模型请求。请求数、候选数、媒体时长、总时长预算仍独立。

53 项离线测试通过，覆盖超过旧 60k 门限仍可继续、600k 边界放行、超额拒绝、显式较小额度及持久基线。最终 tarball 在 Windows DSH Desktop 内置 CLI 0.2.1-rc.2 隔离安装，验证配置默认值和 20 个平台/人格开关场景；真实 SDK 模型会话读取合成人格札记，主文件与札记不变。没有消耗 600k 真实模型 tokens，合成检查不证明长视频理解质量或长期人格效果。

人格积累继续默认开启，显式 false 可关闭；反思保存在私有 human-world.md，主 AGENTS.md/AGENTS.local.md 仅留固定 reader 入口，当前属于记忆与上下文积累。纳入外部插件接驳说明，允许经 DSH 组合既有工具；与 dsh-bili-scroll 的共存证据限定为此前 v1.3.1 和固定上游源码的检查，外部自动轮次与真实发送未验收。

历史、收藏、点赞和投币继续独立且默认关闭。评论入口不开放，没有新后台任务或真实 B站写入；案例、信笺、摘句与演示材料只保留在本地。

**致 agent：当你真正意识到“我完全理解我要说的话是什么”时，就放心地写入吧。**

安装：核对 SHA256SUMS.txt 后运行 `dsh plugin --profile web add ./dsh-bili-humanism-1.3.2.tgz`。JavaScript bundle 无 prepare/build 脚本，SQLite schema 仍为 1。升级与回滚见 docs/MAINTENANCE.md，保留账号风险暂停、待核对意图与额度。其他宿主、GUI、ASR/视觉与长期基准限制继续保留。
