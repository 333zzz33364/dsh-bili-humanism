## DSH B站内容学习插件 v1.7.1

修复单次 CDN 连接重置让整个取稿/抽帧任务失败的问题。GET 仅对传输异常最多尝试三次，每次重新检查授权、取消、截止和持久暂停，并消耗共享请求预算。HTTP/API 风险响应不重试；所有 POST 保持单次发送，未知写入结果继续暂停。

抽帧支持同清晰度、同尺寸 DASH 备选轨道及 backup URL，单段 DURL 可用其备选地址；去重后最多六个。每个目标经过原域名/端口清单，未开放新 CDN，Cookie 不发往字幕或媒体主机。普通网络、HTTP、流读取或地址拒绝可回退，平台风险、大小/请求/总时长预算与取消立即停止。

读取 API GET 支持同一可信凭据文件中可选的现有 `buvid3`。只使用本人提供的值，不获取、生成或轮换指纹；设备值参与缓存身份，增加设备配置后不再命中原会话空缓存，旧缓存与来源保留。这不保证解决 HTTP 412；412 仍持久暂停。四项平台写入独立默认关闭，评论继续关闭。

修正 macOS 安装器测试夹具未规范化系统临时目录的问题，生产路径的符号链接拒绝规则保留。160 项离线测试覆盖新旧功能；本版要求同提交的三系统 CI 与最终 tarball 的隔离真实 Windows DSH Desktop 内置 CLI 0.2.1-rc.2 验收全部通过后才公开 Release，最终结果及安装包 SHA-256 记录在对应发布页。macOS 核心 CI 不代表 macOS DSH 宿主验收。

保留 v1.7.0 的离线质检、每日文字取稿、独立媒体依赖入口、每稿 600k 人工可配额度、最高 480p 与原生图片附件。验收使用合成平台/媒体，不请求真实 B站账号、不执行平台写入、不调用真实模型；不声明语义质量、完整观看或专名正确率。升级和回滚均保留账本、账号额度、未知回执与风险暂停。本版继续为预览版。

## DSH B站内容学习插件 v1.7.0

新增取稿后的离线质检，补上"已经取到稿，还能不能直接用"这一段。`probe READING_ID` 与 `audio-profile LOCAL_MEDIA` 只读本地账本和由人在命令行指定的本地媒体：不联网、不带凭据、不调用模型，模型侧工具 `bili_humanism_probe` 不接受路径、URL 或命令。

输出包括分段数与字数、分段时间覆盖、`charsPerMinute`（按全片）与 `effectiveCharsPerMinute`（按有声段）两个口径及其 `denominator` 标记、给定专名的形态分布与首次出现时间、拉丁串与紧贴中文的 1–2 字符碎片、含繁体字形行数。专名只报 `single_form` / `multi_form` / `absent` 与 `human_review_required`，不判定哪个写法正确：同一写法稳定地错和稳定地对，在这份稿内部无法区分，正确性仍需回源，见 [取稿后的离线质检](QUALITY.md)。

音频剖面把音轨解码为 16 kHz 单声道，按桶计算 RMS（dBFS），阈值取人工值与"中位数 −18 dB"中较大者，连续低于阈值且不短于 `min-run` 的段记为无声段。它测能量，不区分语音、音乐与音效，安静不等于无人说话；用途是修正字/分钟的分母，不构成观影完整性证据。

保留每日 21:30–22:00 的文字取稿、`setup-media`／`doctor`、默认无固定媒体时长拦截、每稿独立 token 额度、最高 480p、32 MiB／90 秒预算与中间视频清理。人格积累默认开启，四项平台写入独立默认关闭，评论入口继续关闭；升级不清除账本、账号额度或风险暂停。

本次已有 147 项离线测试通过，含新增的入参校验、边界与模型可见摘要截断；验证范围为合成文本夹具、合成音频与本地真实音频，未发起真实账号请求或平台写入。完整宿主与安装步骤验收仍待补，桌面界面安装、独立 npm CLI 与其他 DSH 版本未完成验收。本版继续为预览版；不声明真实视频语义准确率或专名正确率。
