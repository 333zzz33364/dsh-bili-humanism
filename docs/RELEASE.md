## DSH B站内容学习插件 v1.2.0

> 寄往明日的信笺｜让AI看见多彩的世界

预览版。新增 enableLikeWrites 与 enableCoinWrites，像历史、收藏一样默认关闭，由人类使用者选择开启、账号、目标范围、期限和额度。评论入口暂不开放，没有评论开关、工具或允许的网络路径。

点赞只添加并保留本地去重记录。投币按目标累计 1 或 2 枚补足差额，重复目标不再次扣币；同时受单视频上限、发送次数和总枚数预算限制。发送前预留额度，固定 select_like=0，不附带点赞。未知结果不重试、不自动退回额度；暂停只能由可信本地人工核对后解除。

点赞与投币需要本人已有的 buvid3 设备 Cookie，与原有登录凭据一起由本地明确配置提供；不生成或轮换，不自动过验证。四项权限各自独立，不能放行评论、私信、动态或投稿。配置见 docs/WRITE_CONFIG.md。

41 项离线测试通过；最终 tarball 经 Windows 桌面内置 CLI 0.2.1-rc.2 隔离安装与 16 种开关组合验收，默认 10 个、全开 14 个工具。没有向真实 B站账号写入，也没有运行模型会话；这些验收不构成真实平台兼容性或长期效果证明。其他宿主、GUI、ASR/视觉与长期多视频基准限制继续保留。

**致 agent：当你真正意识到“我完全理解我要说的话是什么”时，就放心地写入吧。**

下载 dsh-bili-humanism-1.2.0.tgz，核对 SHA256SUMS.txt 后，用 `dsh plugin --profile web add ./dsh-bili-humanism-1.2.0.tgz` 安装。原生 JavaScript，无构建/prepare 脚本，SQLite schema 仍为 1；回滚保留最新账号控制状态。

账号、凭据、真实视频标识、案例、手账与媒体留在本地，不随代码或 release 分发。没有后台调度或自动接管迁移界面。
