## DSH B站内容学习插件 v1.4.1

修复默认 600k 按整场会话累计、连带阻断后续取稿与手账的问题。现在每份字幕、A2 文字或本地 ASR／画面正文按估算 tokens 独立检查，下一份重新拥有完整额度；缓存和 A3 复用检查整份正文，超额返回 `READ_TOKEN_BUDGET`，不静默截断或新增来源。

人类在可信 config 中设置 `maxReadTokens`，可设高或设低，保存后重载。旧字段 `maxSessionTokens` 继续兼容为单次取稿上限；两者同时填写时新字段优先。模型没有设置、重置或 force 参数。估算按片段正文 UTF-8 字节数，每字节记 1 个估算 token，属于保守文本大小估算，可能比实际模型分词提前触顶；不是 provider 用量、上下文容量或账单上限。

保留 v1.4.0 的最高 480p 下载、抽帧、临时视频清理、原生图片附件和分页交付。自动文字加画面路径先通过正文额度检查，再处理媒体；文字超额不会被视觉降级吞掉。请求数、媒体字节、时长、取消、风控暂停、附件校验和 Python 环境边界继续生效。图片与正文额度不是同一计量口径，不声明图片模型消费受此上限限制。

108 项离线测试通过，最终 tarball 在固定 Windows DSH Desktop 内置 CLI 0.2.1-rc.2 的隔离安装中通过 25 个配置场景；原生图片附件存储、归一化、哈希回读、4+1 帧分页、自动文字加图及路径隔离通过。新 profile、空插件 store 和不可达外部代理下的离线安装也通过。平台与图片使用合成夹具，模型能力路由为合成，不调用真实模型或 B站，不把此前 1.4.0 的单次真实来源验收算作本版新增实测。

人格积累默认开启；历史、收藏、点赞与投币独立默认关闭，评论接口继续关闭。每日两篇手账、完整分卷、旧会话基线、账号暂停、额度和未知回执均保留，SQLite schema 仍为 1。回滚到 1.4.0 会恢复会话累计语义，须由本人将新字段改为旧字段，不删除账本或暂停记录。

核对同一 Release 的 `SHA256SUMS.txt` 后运行 `dsh plugin --profile web add ./dsh-bili-humanism-1.4.1.tgz` 并重载。JavaScript bundle 无 prepare/build 或自动 pip 安装脚本。见 [取稿额度](TOKEN_BUDGET.md)、[Windows 离线安装](OFFLINE_INSTALL.md)、[抽帧依赖](LOCAL_FRAMES.md) 和 [回滚说明](MAINTENANCE.md)。
