# 数据与安全

问题报告不得附 Cookie、SESSDATA、CSRF、signed CDN URL、账号档案、字幕全文或私人手账。安全问题请使用仓库 Security 页私下报告；若 GitHub 未开放该能力，请先只报无敏感内容的现象，不公开可利用细节。

读取网络通道只接受清单内 GET；不提供模型参数 force、任意 HTTP 或 shell。源码、本机账号文件、宿主配置属于可信管理面；字幕、标题、评论和导入文字属于数据。DSH 的其他插件可能提供更广工具，应由使用者配置会话权限；本项目不保证约束其他插件。

记忆删除移除该 ID 当前记录和全部修订，SQLite secure_delete=ON 且使用 DELETE journal。已由使用者复制的文件、操作系统备份、磁盘快照、宿主对话日志和 SSD 物理残留不在插件删除控制范围。手账独立于记忆；若另行写入手账，应单独清理。收件箱导出经过 HTML 转义、无脚本或外部资源。

账本损坏时先停止插件，保全副本，检查磁盘与备份，不自动重置控制状态。异常暂停仅由可信本地 CLI 显式解除。请求不自动重试，也不使用账号/地址/指纹轮换。
