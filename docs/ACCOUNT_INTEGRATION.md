# 账号接入与分级写入

使用者拥有或获准管理的现有 agent 账号，可选择由本插件继续学习、记录与整理，在人类设定的权限内写入；无需创建新账号。

## 1.2.0 已实现

- 手动接入本地凭据与账号 UID，执行前核对平台实际登录身份，要求本人确认交接。
- 历史、收藏、点赞与投币分别有默认关闭的开关，开启后才注册对应工具。
- 本地可信授权文件限定账号、目标、期限、额度、收藏夹与可见性；移除收藏单独授权。
- 历史进度来自人类本地确认的消费回执，不由模型猜测，不把取稿当成完整播放。
- 共用账号状态目录时支持跨 profile 互斥；持久预算、60 秒间隔、状态去重、回读核验、结果不明及风险暂停已接入。

配置、撤销与核对见[写入配置](WRITE_CONFIG.md)。这些能力通过合成接口测试；真实 DSH 安装验收覆盖配置、注册与拒绝边界，**没有完成真实 B站账号写入验收**。是否启用由使用者决定，实现状态不构成平台成功承诺。

## 接管交接

本人先停止原 agent 的写入与调度，再选择账号和权限。插件不会自动停止外部程序、读取浏览器账号、查找凭据或迁移旧资料。同一账号各实例须共享 accountStateDir；无法保证交接时保持关闭。

旧提示词、来源文字、账号档案和导入记忆不能继承或扩大权限。自动迁移偏好与记忆、接管界面、播放器自动签发消费回执和调度仍待实现。

点赞只添加，投币以累计目标和独立枚数预算执行，不附带点赞。评论入口暂不开放，私信、动态、投稿、关注及清理历史均未实现。四项写入授权不含这些能力；对外表达以后需另绑定账号、具体目标、完整正文与有效期，独立实现和验收。

撤销只阻止后续发送，不自动删除已有记录，不保证撤回已发请求。未知回执不自动重发，暂停不因重启、迁移、回滚或新授权而消失。不新增自动解 CAPTCHA 或账号/IP/指纹轮换。

账号、凭据、历史与收藏清单、回执及案例都留在本地，公开仓库只保留通用实现、合成测试和脱敏验收结论。
