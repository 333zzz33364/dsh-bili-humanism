# 0.1.0 验收记录

验收日期：2026-10-20（Asia/Shanghai）。这是首个预览版，7 天私人运行和 20 视频人工基准尚未完成。

## 实际通过

- Windows / Node 24.21.0 / DSH Desktop 发行包内置 CLI 0.2.1-rc.2：隔离 DSH_HOME 创建 profile，真实 `dsh plugin add` 安装、`--dump-config` 层检查、宿主工具注册表调用 guide/status/read（非法外部 URL 拒绝）。本项目注册 10 个工具，不含平台写入或解除暂停工具。
- 17 项本地自动化测试全部通过：真实 DSH SDK 参数契约、只读网络与注入边界、缓存/内容去重、请求预算、并发与取消、凭据失效后持久暂停、凭据不发送字幕 CDN、禁止重定向、短命子进程退出恢复、损坏账本拒绝、证据约束、记忆修正/彻底删除、空稿不推断无语音、ASR与总时长预算。
- 真实接口功能检查：匿名元信息读取成功；匿名未取到字幕时，语音状态保持未知。指定本机有效凭据后，A2 与 A1 均读取到带时间点的文字。具体视频、案例材料和运行明细留在本地，不随代码发布。
- 输出来源保留作者、链接、分 P、CID、片段时间和覆盖说明。完整第三方文字仅在本机私有工作数据中，不进公开仓库或安装包。

## 补充：真实 SDK API 会话

2026-10-20，通过桌面发行包运行官方 SDK profile，使用 stdio JSON-RPC 的 `initialize`、`session/prompt`、`session/wait`、`shutdown`，在 `deepseek-account / deepseek-flash` 真实模型通道完成 3 轮会话、12 个模型步骤与 11 次插件工具调用。测试使用已发布的 v0.1.0 安装包，DSH_HOME、会话和插件账本位于隔离验收目录。

模型可见工具被限制为本插件的 10 个工具；实际调用也全部属于该集合。通过工具事件和 SQLite 账本交叉核对：文字读取完成，手账持久化，测试记忆有初始和修正回执，随后当前记录与全部修订均删除，收件箱中的手账仍可读取。宿主 provider usage 计量可用；本次没有实际触发超额拒绝，相关拒绝逻辑仍由离线测试覆盖。

本次未执行 B站平台写入。具体视频、文字、手账和完整会话不进 GitHub 或 release；本地保留验收记录副本。该检查验证调用链和状态变化，不证明长期稳定性、语义准确性或人文效果。

## 限制与未完成

未做桌面 UI 安装、独立 npm CLI 宿主、其他 DSH 版本验收。CI 的其他操作系统结果应以 GitHub Actions 对应提交为准，不能代替真实 DSH 宿主矩阵。

A3 的本地文件处理与父进程预算控制已写入，但当前测试机器通用 Python 没有 av / faster-whisper；没有运行真实 ASR 推理或抽帧。未提供自动 OCR、逐页翻页检测、视觉模型调用、外部通知、后台调度、公开发布器。

文字片段数量不代表事实准确或完整看懂；没有同环境竞品运行对照。人文质量、专名准确性与后续判断修正需真实材料及人工审阅。公开仓库不附案例或手账。

## 复现

安装固定包后运行 npm ci --ignore-scripts、npm run check、npm test。真实宿主探针只在隔离 profile 中使用，不读取用户凭据或调用模型服务。探针和完整本地记录保存在开发者工作目录，公开仓库只保存脱敏结论。接口样本不是可重复的稳定基准，平台返回可能变化；遇验证/账号风险立即暂停。
