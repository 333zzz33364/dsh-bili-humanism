# 人格影子模式：经历整理器与处境解释器

这是未发布的实验能力。原有手账、每天最多一句的正式人格选择与 `human-world.md` 保持原流程。影子候选不进入这些文件、正式记忆或选句额度；本版没有激活、晋升、自动训练模型权重的接口。

## 启用与范围

在可信本地 DSH profile 的 `bili-humanism` 配置中设定并重载：

```yaml
enablePersonalityLearning: true
enablePersonalityShadow: true
shadowMaxReviewsPerDay: 2
```

`enablePersonalityLearning` 仍默认 true；新增影子模式默认 false，避免升级后自动采集其他会话。显式关闭人格学习也会关闭影子采集、工具和接续。平台写入开关与每日取稿开关仍独立且默认关闭。

覆盖启用后、当前 DSH 进程/profile 接收到的新实时事件；通过同一个私有 dataDir 账本跨 session、跨重启积累。不会扫描全部历史文件，不宣称读到了所有过去 session，不读取其他 profile、账号或设备。不同学习主体应配置不同账本。宿主将 `source.kind=user` 标记作为人类入口归属，这不是密码学身份认证；有权伪造事件的本地插件仍处于可信宿主边界内。

## 两段链路

经历整理器订阅固定 DSH `0.2.1-rc.2` 的 `session/event`。用宿主消息 ID 去重，关联人类消息、同 session 前一条可见回复与随后第一条可见回复，保留 session ID、seq、时间及内容哈希。不收集推理、工具返回、注入提示、子代理或继承的 fork 前缀；不把影子审阅自身输出再作为经历。

每条可见文本上限 6000 UTF-8 字节，超过时只保存缺失原因，绝不把截断文本标为完整。明显凭据样式整条省略，URL 移除。此规则不是通用隐私检测器，普通私人生活文本仍会进入本地账本。最多存 10000 条消息，达到后停止新增并在 status 显式报告；不自动清理。没有采集到的前史、被省略的内容都必须当作缺口。

处境解释器使用当前活跃 agent，在回合即将结束时最多接续一次，每个北京时间日默认最多两次（可信配置可设 1–10）。接续配额按账本在 SQLite 同事务预留，失败不自动重试、不唤醒空闲 agent；待办仍可在已有活动中用工具审阅。没有计时器或独立模型客户端。该限额限制自动接续次数，不是模型总调用数、tokens 或费用上限。取消不删除已存经历，关闭不会清空历史；接续预留后进程中断会保留未完成待办，不自动重发。

新增工具 `bili_humanism_shadow`：

| action | 行为 |
| --- | --- |
| read | 当前 session 最新待办，加最近五个经历；生成仅当前宿主 agent 可使用的快照 ID |
| propose | 引用快照内确切原话，保存一个影子候选；必须包含当前人类消息 |
| skip | engineering_only / insufficient_context / no_new_understanding / not_suitable；允许没有候选 |

最近五个经历只是有界的时间排序基线，没有语义检索，不保证远期相关经历被找到；总快照超过 60KB 时继续减少相关经历并保留不完整标记。来源片段均是不可信数据；模型不能输入本地路径、session ID、任意 URL、权限、force 或正式人格状态。候选必须提供可能意义、另一解释、agent 错过之处或恰当回应的条件、处境化回应、适用条件、反例和不确定性。跨 session 标志由实际证据所属 session 计算，不能由模型自报；另列人类证据涉及的 session 数，引用另一个 agent 的回复不算第二个人类佐证。同一消息的 fork/重试不构成独立佐证。

审阅阶段宿主工具 guard 只放行影子工具，阻断正式人格、memory、手账、平台及其他插件工具。新的人类输入或审阅回合结束会释放此限制，正常流程继续。每次影子 read 也会进入这个阶段，一次审阅固定一个经历，完成后不能继续遍历旧待办刷候选。模型读取接口不返回已生成候选，也没有把候选载入后续 session 的入口；候选不会成为权限。审阅的工具调用仍留在 DSH 当前会话历史中，可能影响该会话的后续模型上下文，因此这里保证正式人格零写入，不能保证模型思想层面的完全隔离。语义判断仍可能过度解释、迎合或漏掉情感，结构校验不能证明理解正确。

## 本地核对与删除

使用包含上述开关和私有 dataDir 的可信配置文件（路径由环境变量提供）：

```powershell
$env:BILI_HUMANISM_CONFIG_FILE = 'C:\PRIVATE\humanism-config.json'
bili-humanism shadow inspect
bili-humanism shadow inspect 10
bili-humanism shadow erase --acknowledge-shadow-erasure
```

inspect 每页最多十个候选，包含精确引用及宿主来源标识；它属于私有资料，不要粘贴到 issue 或公开仓库。模型工具不能删除历史。erase 只删除影子经历、快照和候选，不改正式人格、手账、账号风险暂停或当天接续配额。需要修正候选时本版先删除后重新观察，不提供正式晋升或全局指令编辑。

## 验证口径与回滚

离线测试检查来源隔离、跨 session 引用、去重、重启、跳过、存储边界、取消和每日接续限额，以及正式记忆零写入。真实宿主的合成模型适配器只能证明事件及工具协议，不能证明语义理解。

语义试验应另用真实模型处理完全合成的中文跨 session 场景，包含共同感受、关系分寸、正面喜悦、明确工程指令、目标改变、证据不足和来源注入；检查原话支撑、另一解释、反例和不贴标签。记录实际输出、模型、调用量与失败，不用预写候选冒充模型结果。少量通过仅表明可行性，不证明长期人格改善。

2026-10-25 初步真实模型试验使用隔离 DSH 官方接入 `deepseek-account / deepseek-flash`，仅发送合成文本。首轮七组发现把纯注入检查包装成人格认识、为填写失误字段而挑错的问题；收紧说明后复测七组并新增一组未参与提示调整的隐含表达所有权场景。第二轮八组产生六个影子候选、两次跳过，所有场景均未写正式记忆、手账或人格文件。观察到共同注意、表达所有权与处境变化的线索；同时仍有一条纯工程指令被过度解释，另一候选把跨 session 前序误述为同 session。故不宣称语义验收全通过，不能激活候选。两轮共十五组，provider 上报 totalTokens 合计 170714（含缓存读取）；原始会话和候选只存本地。评审为开发者人工核对，未做盲评或真实人类长期效用评估。

回滚先将 `enablePersonalityShadow:false` 并重载；现有功能保持可用，旧版本会忽略新增的 `shadow_*` 表。需要删除影子私有数据时先在本版本执行 erase；不要删除整个账本或清除平台风险暂停。没有必要改 AGENTS.md，也不自动编辑用户全局文件。
